# 📝 To-Do List App

A simple and interactive To-Do List web application built using HTML, CSS, and JavaScript. It allows users to organize and manage their daily tasks through an easy-to-use interface.

## ✨ Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Interactive task management
- Clean and simple interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation

## 📁 Project Structure

```text
javascript/
├── index.html
├── style.css
├── script.js
├── checked.png
├── unchecked.png
└── icon.png
```

## 🚀 How to Run

1. Clone this repository.
2. Open the folder in VS Code.
3. Open `index.html` in your browser.
